# Contributing

This is a personal hobby project for tracking espresso shots on the Ninja Luxe Cafe Pro. It is maintained in spare time, so responses may be slow and not every change will be accepted.

Bug reports and small, focused fixes are welcome:

- Found a bug or have an idea? Open an [issue](https://github.com/Arishawke/luxe_cafe_dashboard/issues).
- Sending a pull request? Keep it focused, and make sure the checks pass before you open it:

```bash
npm install
npm run lint
npm run build
npm test
```

Thanks for taking a look.
